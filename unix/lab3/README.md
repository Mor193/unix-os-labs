**Выполнил:** Истомин Давид, группа 932402

## Задание

Написать консольное приложение на C/C++ с использованием любой библиотеки, но без вызова внешних приложений, которое:

1. Обходит весь указанный каталог и составляет список файлов в нём.
2. Для каждого файла вычисляет хэш (SHA-1).
3. Для всех файлов с совпадающим хэшем оставляет только один экземпляр, а остальные заменяет на жёсткие ссылки, указывающие на оставленный экземпляр.

## Реализация

Исходный код находится в файле `main.cpp`. Приложение реализовано на C++17 с использованием системных вызовов POSIX и криптографической библиотеки OpenSSL (`EVP` API):

- **Рекурсивный обход каталога (`collect_files`)** — выполняется через `opendir()`, `readdir()` и `lstat()`. Отбираются только обычные файлы (`S_ISREG`); каталоги (`S_ISDIR`) обходятся рекурсивно, а символические ссылки, каналы, устройства и сокеты игнорируются. Для каждого файла сохраняются путь, идентификатор устройства (`st_dev`) и номер `inode` (`st_ino`). Список путей сортируется для предсказуемого выбора оставляемого экземпляра.
- **Вычисление SHA-1 (`compute_sha1`)** — файл открывается и читается блоками по 64 КБ через файловые дескрипторы (`open()`, `read()`, `close()`), данные передаются в `EVP_sha1()` без загрузки всего файла в память.
- **Замена дубликатов (`replace_with_hardlink`)** — файлы группируются по паре `(st_dev, SHA-1)`, чтобы не пытаться создать жёсткую ссылку между разными файловыми системами. Если файлы уже указывают на один `inode`, они пропускаются. Замена выполняется безопасно: сначала системным вызовом `link()` создаётся временная жёсткая ссылка в каталоге дубликата, затем `rename()` атомарно заменяет ею исходный дубликат (при ошибке временная ссылка удаляется через `unlink()`).

## Требования и сборка

Для сборки требуется компилятор `g++` с поддержкой C++17 и заголовочные файлы OpenSSL:

```bash
sudo apt install libssl-dev
g++ -std=c++17 -Wall -Wextra -O2 main.cpp -o dedup -lcrypto
```

## Использование

```bash
./dedup <путь_к_каталогу>
```

## Пример проверки

```bash
rm -rf test_dir
mkdir -p test_dir/sub
printf "same content" > test_dir/a.txt
printf "same content" > test_dir/sub/b.txt
printf "other" > test_dir/c.txt
ln -s a.txt test_dir/sym.txt

ls -li test_dir test_dir/sub
./dedup test_dir
ls -li test_dir test_dir/sub
```

После выполнения `./dedup test_dir`:
- у файлов `test_dir/a.txt` и `test_dir/sub/b.txt` становится одинаковый номер `inode`, а счётчик жёстких ссылок увеличивается с `1` до `2`;
- файл `test_dir/c.txt` с другим содержимым остаётся отдельным;
- символическая ссылка `test_dir/sym.txt` не затрагивается.
